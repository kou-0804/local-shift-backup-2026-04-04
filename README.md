# 放射線技師勤務表自動作成システム

> **Web アプリ版（院内サーバー）をお探しの方へ**：運用者・開発者向けガイドは
> [`docs/webapp/README.md`](docs/webapp/README.md) を参照してください（生成・手修正・
> マスタ管理・認証・Windows デプロイ）。以下は従来のローカル CLI の手順です（引き続き利用できます）。

このシステムは、放射線技師の日勤・夜勤シフトを自動作成し、Excel形式で出力するPythonアプリケーションです。
OR-Toolsを使用した数理最適化により、複雑な制約条件（スキル要件、夜勤間隔、特殊配置ルールなど）を満たす勤務表を生成します。

## � 初心者向けクイックスタート（ターミナル操作手順）

ターミナル操作に慣れていない方でも、以下の手順通りに入力すれば実行できます。

### 手順1: ターミナルを開く
Macの「アプリケーション」フォルダ内の「ユーティリティ」フォルダにある「ターミナル.app」を起動してください。

### 手順2: フォルダに移動する
以下のコマンドを入力し、Enterキーを押してください。
（デスクトップに `local-shift ver1` という名前でフォルダがある場合の例です）

```bash
cd ~/Desktop/"local-shift ver1"
```

### 手順3: プログラムの準備（仮想環境の有効化）
以下のコマンドを入力し、Enterキーを押してください。
```bash
source .venv/bin/activate
```

※ 成功すると、コマンドの行頭に `(.venv)` という文字が表示されます。

### 手順4: 勤務表を作成する
作成したい年と月を指定して実行します。（例：2026年1月分）
以下のコマンドを入力し、Enterキーを押してください。

```bash
python main.py --year 2026 --month 1
```


### 手順5: 結果を確認する
画面に「✅ 勤務表作成完了」と表示されれば成功です。
`local-shift ver1` フォルダの中にある `output` フォルダを開くと、Excelファイル（`勤務表_2026年1月.xlsx`）が作成されています。

## 📁 ディレクトリ構成

- `main.py`: 実行用メインスクリプト
- `shift_scheduler/`: ソースコードおよびデータディレクトリ
    - `src/`: プログラム本体
    - `data/`: **(重要)** 入力データ（CSVファイル）を配置する場所
- `output/`: 生成されたExcelファイルが出力される場所
- `tests/`: 検証用スクリプト

## 🛠️ 主な機能

1. **夜勤スケジューリング**: スタッフのスキルと条件に基づき、3名体制の夜勤シフトを作成。
2. **日勤スケジューリング**: 夜勤明けや希望休を考慮し、場所ごとの必要人数・スキル要件を満たす日勤配置を作成。
3. **パワーバランス制御**: 特定の場所（CT、ポータブルなど）におけるスキルランクの偏りを防止。
4. **特殊配置ルール**: 特定の曜日（アンギオ火曜）、週（HB第1金曜）などの固定ルールを適用。
5. **月別公休数の設定**: `公休数マスタ` により、月ごとの正確な公休日（8〜10日）を自動配置。
6. **業務拡大（育成ペアリング）**: 指導者と若手のペアを特定のモダリティに優先配置し、実戦トレーニングをサポート。
7. **Excel出力**: 既存のフォーマットに準拠したデザインで出力。

## ⚠️ 注意事項

- データファイルに欠損や不整合があると、正常にスケジューリングできない場合があります。
- 最適化計算には数秒〜数分かかる場合があります。
